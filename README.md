# Josh Bachynski podcast booking site

Static website for `joshbachynski.com`, designed to give podcast producers a fast, source-linked booking reference.

## Preview locally

From this directory:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Content maintenance

- Main positioning and page copy: `index.html`
- Appearance records: `assets/appearances.js`
- Visual system and responsive layout: `assets/styles.css`
- Filtering, motion and interface behavior: `assets/site.js`

The booking address is `media@joshbachynski.com`. Configure or forward that mailbox before launch.
